html Style Guide Notes 

        - Declare document type
        - Never skip the title element
        - Try to keep a lang element in the html
        - Keep in metadata charset and ideally viewport
        - Ideally, keep head, body, and html tags
        - Close empty elements
        - Lowercase element & attribute names, Case Matters!
        - Close all html elements
        - Always quote attribute variables
        - Always specify alt, width, and height for images
        - Avoid spaces around equal signs to better group entities together
        - Avoid long code lines
        - Use blanklines to separate code blocks
        - Use indentation (2 spaces) to show nesting
